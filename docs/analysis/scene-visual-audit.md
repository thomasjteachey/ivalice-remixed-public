# Scene visual audit (2026-11-24)

The black battlefield behind dialogue is a live renderer state: the native join-screen function sets `exe+0x2FF9E00` to 1 on exit, including when the event continues on the same map. A PC replay at Mandalia reproduced the black field after Luso's card. Clearing that flag after the state-7 wait restored the field immediately, and the built `C7` event routine now does so before removing the dark screen.

The builder scans every ported ReMixed event for the state-7/wait sequence inside a dark screen. All eleven occurrences in eight event families are patched and counted: 0x008 (1), 0x040 (2), 0x06E (3), 0x07B (1), 0x0A3 (1), 0x0EB (1), 0x107 (1), and 0x11B (1). An unlisted or changed count fails the build. PC end-to-end replays passed for Mandalia (one card) and Araguay (two cards), including a live renderer-flag check after the cards and return to the world map. The other families have build/disassembly coverage, not full gameplay replays.

The separate midbattle fade issue was found in the Grog Hill event 0x114 and the 1-A rescue event 0x112: both could run dialogue after an opaque `ColorScreen` without a `Reveal`. Each has an explicit reveal before its dialogue. The Grog midbattle and postbattle runs share the fix. All 129 shipped custom event scripts were disassembled and searched for this fade/dialogue pattern. The Luso scenes 0x0EB and 0x107 also reached dialogue after a fade, but their black field came from the join-screen exit flag described above. No other match was found. This scan does not prove every scripted visual transition is correct.

The wrong Bryn/Lorne sprite at Grog Hill came from those two events copying a graphic from a roster or battle record that can be absent. The build supplies their intended graphics when absent, and the speech-face hook supplies their matching faces. The same scan found no other custom event that copies the graphic field at offset `0x15F` this way.

The first Bryn/Lorne speech-face hook checked only the unit-name ids 0x69/0x6A. The fortress Knight in event 0x0F4 also has 0x69, although the event changes his graphic to male Knight 0x64. On the Deck, his greeting therefore showed Bryn's Dancer portrait. The hook now requires the name and matching graphic (Bryn 0x69/0x83; Lorne 0x6A/0x38). A regression check includes the Knight's 0x69/0x64 combination.

For portraits, the build compares all 64 entries in ReMixed's `EVTFACE.BIN` against the original and finds exactly four changed pictures: set 0 slots 7 and 8, set 1 slots 6 and 8. It ships all four pictures as remaster face textures and maps those face-set entries to them, with a build check for the exact source differences and an offline check for the runtime table. The dream event 0x0F9 had selected set 1 slot 6 (Orlandeau) for Gareth; its 15 messages now select slot 8. A PC replay shows Gareth's Knight sprite and his own portrait. The rescue event 0x112's five Agrias messages selected her off-field unit, yielding an empty portrait; both generated copies now select her set 0 slot 7 explicitly. Disassembly confirms those messages and the installed texture/table mapping. A PC capture of that midbattle branch remains to be obtained; the replay used here reached the opening and then the battle without triggering the revival branch.
