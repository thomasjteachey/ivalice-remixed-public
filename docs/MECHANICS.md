# ReMixed mechanics

Every custom mechanic found in ReMixed's code, what it does, and where it lives
on the PS1. This is the porting tracker for anything that needs a C# hook on
The Ivalice Chronicles. Data-table changes (stats, skillsets, items, battles)
are tracked in [FEATURES.md](FEATURES.md). What's left, as a checklist, is in
[GAMEPLAY_TODO.md](GAMEPLAY_TODO.md).

Found by reading the code that `tools/codemap.py` isolates. The detailed notes,
with entry points, inputs and outputs for each mechanic, are in
[analysis/](analysis/):

- [battle-80150000.md](analysis/battle-80150000.md): BATTLE.BIN new code 0x80150000–0x80157FFF and in-place patches
- [battle-80158000.md](analysis/battle-80158000.md): BATTLE.BIN new code 0x80158000–0x801610D4
- [world-and-menus.md](analysis/world-and-menus.md): main exe, world map and menu overlays

**Confidence** is about what the code does: **high** means read and understood,
**medium** means the logic is clear but the purpose is a best guess, **low**
means partly read. Rows marked ✔ were also spot-checked against the code by hand.

**Status:** `todo` · `ported` · `skip` (not needed on the remaster)

Addresses are PS1 RAM. Ability ids are hex; ReMixed reuses many vanilla
ability slots, so a slot's vanilla name may not be ReMixed's name for it.

## Where the options live

ReMixed has no separate settings block. Its Extra Options are event flags and
event variables, which are part of the save file. Event variables 0x00–0x7F are
4-byte words from 0x8005771C. Flags 0x80 and up are bits from 0x8005791C, numbered from the
low bit: flag 0x80 + 8 × k + b is bit 1 << b of byte k (0xD8 is 0x80057927 & 0x01).
The Extra Options menu is event 0xC9 in `EVENT/TEST.EVT` (its text starts at 0x192BF8); its Combat
Adjustments, Event Script Version and Nemesis System menus are event 0x11C (text and code from
0x238004). `tools/events.py 0xC9` and `tools/events.py 0x11C` list the code, with `--text` the
menus' text, and `tools/option_reads.py` (`--wide` for helper calls) finds the code that reads the option bytes. Every
option's default is 0 and its menu lists the default first: a two-choice option's flag is set
for the second choice, and a four-choice one stores the choice's index in its two flags (low
flag bit 0), except Zodiac Compatibility. The
first time it runs it sets the defaults (byte 3 bit 0x10 of var 0x14 marks that; `tools/events.py 0xC9` lists it: var 0x14 = 0x1004647D, flags 0xE6, 0xEE, 0xEF, 0xF0 and 0xF1 cleared, every other flag left at a new game's 0), with
variable opcodes ReMixed adds: 0xAC and 0xAD set var = value << 16, 0xAE and 0xAF set var =
value (the odd ones take the value from another variable; the interpreter's range check at
0x80143D5C was widened from 0xB0–0xBE to 0xAC–0xBE, handled at 0x801597C0).

On the remaster each save keeps its own, where ReMixed keeps them (`Patches/SaveOptions.cs`), changed in the game on the ReMixed tab of Settings (`Patches/OptionsPage.cs`: a group picked on its first row and the group's options below it, as ReMixed's own menu has them; REMASTER.md, "The Options screen"). A save without them (a new game, or one from before) takes the Reloaded-II mod settings ("Configure Mod"; `Options.cs`, saved as Config.json in the mod's config folder and read once at startup), defaulting to what a ReMixed player meets once its story begins: Player Deaths, General Deaths, JP gain, Spillover JP, EXP gain, Back Attacks, Bravery/Wariness, Knockback, Minimum Weapon Range, Poaching Odds, Poison & Regen, Auto Renew, Starting MP, Zodiac Compatibility, Sexuality, Power Modes (presets and Custom), Job Level Settings, Enemy Job Settings, Rare Equipment, Cast Time ("Cast instantly"), Fixed or Minimum Levels, Enemy Level Boost, Job Stats, Bonus EXP & JP on Victory and the Nemesis System. ReMixed's menus (events 0xC9 and 0x11C): Unit Levels, Stats & Equipment (Improved Level Scaling, Fixed or Minimum Levels, Enemy Level Boost, Job Level Settings, Enemy Job Settings, Job Stats, Rare Equipment, Monster Reactions), Permadeath (Player Deaths, General Deaths), JP and EXP (JP Gain, Spillover JP, EXP Gain, Bonus EXP & JP on Victory, JP Refund, JP Scroll Glitch), Spellcasting (Auto Renew, Starting MP, Cast Time), Combat Adjustments (Bravery/Wariness, Poaching Odds, Back Attacks, Knockback, Minimum Weapon Range, Poison & Regen, Guest Control, Power Modes, Zodiac Compatibility, Sexuality), Event Script Version and Nemesis System. Each option block in the event loads its flag, shows a menu, and sets the flag for its second choice.

So ReMixed's AI counts giving Protect, Shell or Wall, and not Berserk or Chicken on a stopped or sleeping target. 0x8019F535 starts at 99 where vanilla's was 100 (0x8019630C), but no BATTLE.BIN code reads it by that address, so its user isn't found (searched again 2026-11-04: nor through the base 0x8019F3C4 the setup loads, which puts it at +0x170; settled, nothing to port, like the monster Attack record's range above). Not worked out: and three changes that turned out to be in the target-selection code, not the AI (0x801AF770 and 0x801AFF18, from 0x8017AE8C next to the target-area routine): 0x801AF7E4 stops skipping Jumping units (+0x58 & 4) in a 21-unit loop, 0x801B0330 stops skipping units of the same team (+5 against +0x1BA, & 0x30), 0x801AFB18 a rewrite's epilogue. The five in the per-skillset list 0x8019A5F8 belong to Two Spells (its AI lists, ported with it).
