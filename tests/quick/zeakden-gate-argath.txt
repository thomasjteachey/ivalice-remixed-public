# The Argath campaign's last battle at Fort Zeakden (ReMixed's event 0x102, the port's scenario 0x323), vanilla's
# 0x04F retold: the tower's door opens after Zalbag and Argath's first lines (field object 0), the kidnapper comes
# out onto the bridge with Tietra, and after the fourteenth line he goes back in and the door shuts (object 1), which
# the remaster moves the redrawn map for as its scene 79's (the map's one animation), the build's
# MAP_MOVEMENT_SCENES. The redrawn map draws the door open until that animation has played, since the remaster's own
# scene opens it as it starts; ReMixed's is shut through its first lines and in the battle after the scene. So the
# event puts the animation on its last frame as it starts (the code mod's line "set on its last frame", before the
# scene and again before the battle) and back on its first after object 0 ("set to state 1"), the build's
# MAP_ANIMATION_CALLS. Framed: the door shut as the camera passes it (the `first` film, some 15 to 25 s in), open
# with the kidnapper in it (`opened`), shutting (`second`), and shut in the battle (`battle`).
# How each part is framed: the scene is played fast to a line or two ahead, then at its own speed while the code
# mod's line is waited for ("map movements: scenario ...'s field object N moves the redrawn map as the remaster's
# scene M's", logged the first time each object starts in a run), with a press every 4 s to close the lines on the
# way and a frame every second (film=: NAME-NNNN.png, tenths of a second into the wait), so the last of them is
# the map just before the part moves, however the lines closed. Then a frame at once (NAME-at), six peeks of the
# redrawn map's first animations (kind, state: 2 is running), and frames by the clock (NAME-after-NN, seconds).
#   python -I tools/quick_test.py --restart tests/quick/zeakden-gate-argath.txt
