# The Argath campaign's reprimand in Eagrose Castle (ReMixed's event 0x00F, the port's scenario 0x313: "What madness
# possessed you that you would abandon your posts..."), vanilla's 0x02D retold: after Dycedarg's question the doors
# open (field objects 3 and 5). The remaster's own scene there (45) moves the redrawn map's animation 0 for object 3
# by the scene's number, and has its own instruction (0xCD: animation 2) after object 5. ReMixed's scene under the
# port's number got neither; now the code's list is asked as scene 45 (the build's MAP_MOVEMENT_SCENES: the first
# line) and the event calls the code mod's routine after object 5 (MAP_ANIMATION_CALLS: the second line). The scene
# is played fast to the doors, then framed at its own speed.
#   python -I tools/quick_test.py --restart tests/quick/argath-reprimand-doors.txt

wait log "map movements: map animation 2 \(kind \d+\) set to state 2" timeout=30
wait seconds 2
shot doors-opening
wait seconds 4
shot doors-open
